# AGENTS.md — Governança de Agentes e Personas (GymFlow API — SDD + ORM + Auth)

Este repositório utiliza **Spec-Driven Development (SDD)** no **Google Antigravity**.
Todos os agentes (`[Spec Auditor]`, `[Tech Lead]`, `[Backend Coder]`, `[QA Engineer]`) obedecem rigorosamente aos artefatos:
- `@[STYLEGUIDE.md](STYLEGUIDE.md)`: Constituição Técnica (Python 3.12+, FastAPI, Pydantic v2, SQLAlchemy 2.0 ORM, PyJWT HS256, RBAC e RFC 9457).
- `@[SPEC.md](SPEC.md)`: Especificação de domínio da **GymFlow API** (`Students`, `Workouts`, `Routines`, `Exercises`, `Executions`, `Auth`).
- `@[PLAN.md](PLAN.md)`: Roteiro sequencial das 6 fases de engenharia.
- `@[GymFlow API.apidog.json](GymFlow API.apidog.json)`: Contrato OpenAPI 3.0.1 exportado do Apidog.
